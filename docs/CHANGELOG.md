# Changelog

## V2.1 — 2026-10-05
- QA-протокол исправлен с учётом реальной памяти Projects: Project-only изолирует проект от внешней памяти, но не изолирует чаты внутри проекта.
- Введён порядок теста: отдельный чат → фиксация ответа → удаление чата → следующий вопрос + контроль загрязнения памяти.
- В валидатор добавлена жёсткая проверка полного вхождения вопроса из образцового диалога в тестовый вопрос и наоборот.
- Для единичных функций Finance / Legal / Document Control убраны несуществующие «главный/ведущий/старший» наставники; наставник назначается из реальной учебной структуры.
- Учебная штатная карта перенесена непосредственно под раздел «Структура».
- Документация развёртывания уточнена: Project-only memory можно изменить после создания; расшаривание — только после зелёного QA.


## V2 — 2026-10-05
- Основной контур развёртывания переключён на ChatGPT Project; Custom GPT оставлен только как бонус/совместимость.
- Разведены два понятия времени: целевой срок процесса и ориентир ответа подразделения.
- Добавлена учебная штатная карта на 38 человек без увеличения числа Knowledge-файлов.
- Переписаны 11 регрессионных вопросов, которые были слишком похожи на образцовые диалоги.
- Валидатор теперь проверяет лексическую независимость тестов от обучающих диалогов.
- В DENYLIST возвращены `dimaseo` и `seodom`.
- `eval/results.csv` больше не игнорируется Git: это доказательство QA.
- Финальный score считается успешным только при заполнении всех 24 фиксированных вопросов.
- Добавлен QA-протокол: 5 повторных пограничных прогонов + 6 слепых вопросов.
- Уточнены источники 2025–2026 по персональным данным, ЭКДО и статусу GPT/Projects.
