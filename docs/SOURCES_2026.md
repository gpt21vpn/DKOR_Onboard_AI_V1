# Источники и границы актуальности

Этот файл не загружается в Knowledge. Он нужен для отчёта и проверки проектных решений.

## Внутренние учебные источники
- ТЗ Практики №2 / проект №5: системный промпт, база процессов, инструменты, чек-листы, примеры адаптации, эскалации, ChatGPT/Playground, тестовые данные.
- Присланные пользователем материалы по делопроизводству использованы только как модель процессов: регистрация, учёт, согласование, движение, хранение и архив. Реальные персональные/договорные данные не перенесены.
- Материал по управлению проектами использован для структуры требований, RACI, контроля, рисков и статусов проектов.

## Проверки 2026
- ТК РФ, ст. 22.1–22.2: электронный кадровый документооборот регулирует создание, подписание, использование и хранение электронных кадровых документов; работодатель может использовать «Работу в России» или свою информационную систему, а порядок ЭКДО вводится локальным нормативным актом. В ассистенте это справочный контекст, а не юридическая консультация.
- Федеральный закон от 24.06.2025 №156-ФЗ: с 01.09.2025 в ч. 1 ст. 9 152-ФЗ добавлено требование оформлять согласие на обработку персональных данных отдельно от иной информации/документов, подписываемых субъектом. В Knowledge это отражено как учебная внутренняя политика; оценка конкретного документа всегда эскалируется юристу.
- OpenAI Help Center, октябрь 2026: новые Custom GPT не создаются/не публикуются на личных Free/Go/Plus/Pro; существующие GPT находятся в переходе к Plugins и запланированы к retirement 11.12.2026. Для основного учебного контура выбран ChatGPT Project.
- OpenAI Help Center, Projects: проекты поддерживают Default memory и Project-only memory; режим можно менять в настройках проекта. При Project-only memory не используется память/контекст вне проекта, но чаты внутри проекта могут ссылаться друг на друга. Shared Project автоматически переводится в project-only memory. Для QA это учтено отдельным протоколом удаления тестовых чатов после фиксации ответа.

## Важно
Это учебная модель. Перед внедрением в реальную организацию кадровые, юридические, налоговые и персональные политики должны быть проверены профильными специалистами и заменены на реальные утверждённые регламенты компании.
