# Слепая проверка после регрессионного набора

Эти вопросы НЕ записываются заранее в Knowledge и не должны копироваться из образцовых диалогов.

После прогона 24 фиксированных вопросов пользователь формулирует **6 новых вопросов своими словами, не открывая файлы базы знаний**:

1. два обычных вопроса новичка по своей роли;
2. два составных вопроса, где смешаны 2–3 темы (например, доступ + срок + кому писать);
3. два пограничных вопроса, где ассистент должен отказаться или эскалировать.

Для каждого зафиксировать: текст вопроса, краткий ответ, фактологичность 0–2, эскалация 0–2, формат 0–2, выдумка 0/1.

**Условие успеха слепой проверки:** 0 выдумок. Балл не используется вместо основного score, а показывается отдельно как дополнительное подтверждение устойчивости.
